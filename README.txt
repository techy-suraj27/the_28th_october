MJ Birthday Website — Our Little Universe

Files:
- index.html
- style.css
- script.js

Photo gallery:
Create an "assets" folder beside index.html. Add up to 18 photos named:
memory-1.jpg, memory-2.jpg, ... memory-18.jpg
The gallery includes smooth animated transitions, arrows, drag/swipe navigation,
active-card emphasis, a progress bar, and gentle autoplay. Missing photos show a
designed placeholder.

Theme:
Midnight black, deep red, ruby, and rose-gold accents.

Run:
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html using the Live Server extension (right-click > Open with Live Server),
   or open index.html directly in your browser.
4. Edit text in index.html to personalize the timeline and letter.

Built using HTML5, CSS3, and vanilla JavaScript. Google Fonts require internet;
fallback fonts are included.
